# Read further, with a purpose

These links are external readings. Their prose, figures and code are not bundled.

Start with the [CDC/EPA case-study guide](case-studies.md) for six original activities connected to the real-data lessons. Full dated citations and partner credits are in the [README](https://github.com/jltobias/JupyterLite-OneHealth#citations-and-attributions).
